- [createTransfer](https://docs.routefusion.com/reference/create-transfer.md): The createTransfer mutation accepts initial data for transfer. This does not initiate the transfer.
- [createWalletTransfer](https://docs.routefusion.com/reference/create-wallet-transfer.md): The createWalletTransfer mutation creates a transfer to move funds from one wallet to another. finalizeWalletTransfer must be called to execute the transfer. **getTransferQuote must be called in the wallet to wallet transfer flow.**
- [finalizeTransfer](https://docs.routefusion.com/reference/finalize-transfer.md): The finalizeTransfer initiates the execution of the transfer.
- [finalizeWalletTransfer](https://docs.routefusion.com/reference/finalize-wallet-transfer.md): The finalizeWalletTransfer mutation executes the wallet to wallet transfer.
- [getTransferQuote](https://docs.routefusion.com/reference/get-transfer-quote.md): The getTransferQuote mutation locks in a rate for a transfer for a limited amount of time.
- [updateTransfer](https://docs.routefusion.com/reference/update-transfer.md): The updateTransfer mutation allows you to update any attribute of the transfer before finalizing.
- [Sandbox - changeTransferState](https://docs.routefusion.com/reference/changetransferstate.md): The changeTransferState allows for setting the state of a transfer in sandbox to mimic production workflows. This will fire the appropriate the webhook.

- [getRate](https://docs.routefusion.com/reference/get-rate.md): The getRate query fetches the current rate for a currency pair. This does not lock a rate for a transfer. You can lock a rate with the getTransferQuote mutation.
